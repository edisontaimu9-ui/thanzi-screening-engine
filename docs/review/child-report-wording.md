# Child report wording: review sheet

Wording version `child_report_wording_0.1`. Status: **draft_pending_clinical_review**. Generated by `scripts/export_report_wording.py` from the code: edit the code, not this file.

**What to decide.** For each line write Approve, or Change with your wording, or Reject. Check three things in every line: it never states or hints at a diagnosis, it never reassures (no "well", "normal", "safe"), and a missing or empty result is said to be not reassurance.
