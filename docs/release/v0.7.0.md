# Thanzi screening engine v0.7.0: Release Candidate, Not Validated

Decision support only. Not a diagnosis. A trained clinician makes the final decision.

This is a release candidate for review and deployment rehearsal. It has **not** been clinically validated, has not been
run on real patient data, and has not been load tested on target servers. The CMAM 2016 rules are encoded and tested for
behaviour; their clinical correctness needs review of the case pack by a qualified clinician.

## What is in this release

- `thanzi-screen-v0.7.0-image.tar.gz`: the Docker image (`docker load`). Stateless. Runs as a non-root user. Needs
  `THANZI_GATEWAY_KEY` (and optionally `THANZI_AUDIT_KEY`).
- `thanzi-screen-v0.7.0-sbom-image.cdx.json`: CycloneDX SBOM of the image, including operating system packages.
- `thanzi-screen-v0.7.0-sbom-runtime.cdx.json`: CycloneDX SBOM of the pinned Python runtime dependencies.
- `SHA256SUMS`: checksums of every file. Verify them before loading the image.
- `test-report.md`, `traceability.md`: what was tested, how, and what was not.
- `case-pack.xlsx`: synthetic scenarios and engine results for clinical review.
- `openapi.json`: the API contract.
- `deployment-runbook.md`: deployment instructions.

## Not included, on purpose

- No registry publishing. Publishing to a container registry is a deployment decision.
- No TLS, rate limiting or audit logging. Those belong to the gateway.
- No real data. The ML flags are advisory and trained on synthetic data only.
